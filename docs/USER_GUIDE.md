## 1. Что это и как работает

Система состоит из двух сторон.

**Агент** устанавливается на компьютеры сотрудников (MSI, в том числе через групповую политику) и работает в фоне без значка и окон. Он состоит из двух программ:

| Программа | Что делает |
|---|---|
| `LanMessengerAgent.exe` | Windows-служба «LAN Messenger Agent». Запускается вместе с системой от LocalSystem, принимает сообщения на TCP-порту 5600, хранит их и отправляет отметки о прочтении. |
| `LanMessengerUI.exe` | Запускается при входе пользователя в Windows, работает скрыто, показывает окно сообщения. |

Разделение вынужденное: служба Windows не может показывать окна пользователю, поэтому окно показывает отдельная программа в сессии пользователя.

**Отправитель** — приложение для ПК или смартфона. Вы вводите диапазон адресов и текст, нажимаете «Отправить» и видите таблицу по каждому адресу.

Путь одного сообщения:

```
Отправитель ──(1) сообщение, TCP 5600──► Служба агента ──(2) "ack"──► Отправитель: «Доставлено»
                                              │
                                              │ (3) UI-хелпер забирает сообщение
                                              ▼
                                   Окно у пользователя, кнопка «Прочитано»
                                              │
Отправитель ◄──(4) отметка, TCP 5601── Служба агента ◄── пользователь нажал кнопку
 «Прочитано»
```

* **Доставлено** — служба агента приняла сообщение (она отвечает сразу, даже если пользователь ещё не вошёл).
* **Прочитано** — пользователь нажал кнопку «Прочитано» в окне.

## 2. Требования

**Компьютеры-получатели**

* Windows 10 / 11 или Windows Server 2016+ (64-бит).
* Права администратора только на время установки.
* Доступность входящего TCP-порта 5600 от отправителя.

**Отправитель для ПК:** Windows 10/11 (64-бит). Входящий TCP-порт 5601.

**Отправитель на смартфоне:** Android (сборка в Qt Creator). Телефон в той же сети (Wi-Fi) или по VPN, из которой видны компьютеры.

**Для сборки** (если собираете сами): Qt 6.11 (MinGW 64-bit), CMake, Ninja, WiX Toolset 3.14 — только для MSI.

## 3. Быстрый старт

1. Скачайте WiX Toolset 3.14 (zip с бинарниками) и распакуйте в `installer\wix314\`.
2. Соберите MSI с вашим ключом:
   ```powershell
   .\installer\build-msi.ps1 -SharedKey "ПридумайтеДлинныйКлюч"
   ```
3. Из папки `dist\` возьмите `LanMessengerAgent.msi` — установите на компьютеры (раздел 6).
4. Запустите `dist\LanMessengerSender\LanMessengerSender.exe`, введите тот же ключ.
5. Укажите диапазон, например `192.168.1.1-254`, введите текст, нажмите «Отправить».

## 4. Сборка из исходников

### В Qt Creator

1. `Файл → Открыть файл или проект…` → выберите `CMakeLists.txt` в корне проекта.
2. Выберите комплект **Desktop Qt 6.11.2 MinGW 64-bit**, нажмите «Configure Project».
3. Слева в дереве проекта будут папки: `common`, `sendercore`, `agent`, `agentui`, `sender`, `sendermobile`, `tests`.
4. Выберите цель запуска (внизу слева, значок монитора): `LanMessengerSender` — отправитель; `LanMessengerMobile` — мобильный интерфейс (на ПК запустится в окне телефона); `LanMessengerAgent` — агент.
5. `Ctrl+B` — собрать, `Ctrl+R` — запустить.

### Из командной строки

```powershell
$env:PATH = "C:\Qt\Tools\mingw1310_64\bin;C:\Qt\Tools\Ninja;C:\Qt\6.11.2\mingw_64\bin;$env:PATH"
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=C:/Qt/6.11.2/mingw_64
cmake --build build
```

Исполняемые файлы окажутся в `build\agent`, `build\agentui`, `build\sender`, `build\sendermobile`, `build\tests`.

### Запуск без установки (отладка)

Агент можно запустить как обычное консольное приложение, без службы и реестра:

```powershell
$env:LM_SHARED_KEY = "testkey"
.\build\agent\LanMessengerAgent.exe --console
```

В соседнем окне запустите `LanMessengerUI.exe` (покажет окна сообщений) и `LanMessengerSender.exe` (ключ `testkey`, диапазон `127.0.0.1`).
Автоматическая проверка полного цикла: при запущенном агенте выполните `.\build\tests\lm_selftest.exe` — в конце должно быть «ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ».

## 5. Создание MSI

```powershell
.\installer\build-msi.ps1 -SharedKey "ВашКлюч"
```

Параметры скрипта:

| Параметр | По умолчанию | Назначение |
|---|---|---|
| `-SharedKey` | случайный | Общий ключ, который вшивается в MSI. Если не указан — генерируется и записывается в `dist\sharedkey.txt`. |
| `-WixDir` | `installer\wix314` | Папка с `candle.exe`, `light.exe`, `heat.exe`. |
| `-QtDir` | `C:\Qt\6.11.2\mingw_64` | Каталог Qt. |
| `-MingwDir` | `C:\Qt\Tools\mingw1310_64` | Каталог компилятора. |

Скрипт собирает проект, раскладывает Qt-библиотеки (`windeployqt`) и строит MSI. Результат в `dist\`:

| Файл | Назначение |
|---|---|
| `LanMessengerAgent.msi` | Установщик агента (около 25–30 МБ). |
| `LanMessengerSender\` | Портативная папка отправителя для ПК — скопируйте на рабочее место администратора. |
| `sharedkey.txt` | Использованный ключ. **Храните в безопасном месте.** |

Что делает MSI: копирует файлы в `C:\Program Files\LAN Messenger Agent`, регистрирует и запускает службу (автозапуск), открывает входящий TCP 5600 в брандмауэре Windows, записывает ключ в реестр, прописывает автозапуск `LanMessengerUI.exe` при входе любого пользователя.

## 6. Установка агента

### 6.1. Через групповую политику (GPO)

1. Положите `LanMessengerAgent.msi` в сетевую папку, доступную **компьютерам** (группе «Domain Computers») на чтение, например `\\server\deploy\LanMessengerAgent.msi`. Используйте сетевой путь, а не локальный.
2. Откройте консоль управления групповой политикой, создайте или выберите GPO, привязанную к подразделению (OU) с нужными компьютерами.
3. `Конфигурация компьютера → Политики → Конфигурация программного обеспечения → Установка программного обеспечения`.
4. Правый клик → `Создать → Пакет…`, выберите MSI по сетевому пути → способ развёртывания **«Назначенный»** (Assigned).
5. Установка произойдёт при следующей загрузке компьютера (принудительно: `gpupdate /force` и перезагрузка).
6. UI-хелпер начнёт работать при **следующем входе** пользователя в Windows.

Другой ключ для отдельных групп (без пересборки) — через трансформ (MST):

1. Откройте MSI в Orca (входит в Windows SDK) → `Transform → New Transform`.
2. В таблице `Property` измените значение `SHAREDKEY`.
3. `Transform → Generate Transform…` — сохраните `.mst`.
4. В свойствах пакета GPO → вкладка «Изменения» → добавьте `.mst`.

### 6.2. Вручную

От имени администратора:

```powershell
msiexec /i LanMessengerAgent.msi /qn                    # тихая установка
msiexec /i LanMessengerAgent.msi /qn SHAREDKEY=НовыйКлюч # с другим ключом
```

Проверка:

```powershell
Get-Service LanMessengerAgent                           # Status: Running
Test-NetConnection 192.168.1.10 -Port 5600              # с машины отправителя: TcpTestSucceeded: True
```

После ручной установки окно сообщения появится у пользователей при следующем входе в Windows. Чтобы не ждать — запустите `C:\Program Files\LAN Messenger Agent\LanMessengerUI.exe` в сессии пользователя.

## 7. Работа с отправителем для ПК

Запустите `LanMessengerSender.exe`. При первом запуске разрешите приложению входящие подключения в брандмауэре Windows (нужно для получения отметок «Прочитано», порт 5601).

### Поля

| Поле | Описание |
|---|---|
| **Диапазон IP** | Кому отправлять. Форматы ниже. Запоминается. |
| **Ключ** | Общий ключ (тот же, что в MSI). Запоминается. |
| **Заголовок** | Необязательно. Показывается крупно над текстом. |
| **Сообщение** | Текст, до 20 000 символов. |

### Форматы диапазона

Можно комбинировать через запятую, пробел или с новой строки.

| Запись | Что означает |
|---|---|
| `192.168.1.15` | один адрес |
| `192.168.1.10-192.168.1.50` | диапазон адресов |
| `192.168.1.10-50` | краткая запись, меняется последний октет |
| `192.168.1.0/24` | вся подсеть (без адресов сети и broadcast) |
| `192.168.1.0/24, 192.168.5.20-30` | несколько диапазонов |

Максимум — 65 536 адресов за одну отправку. Повторяющиеся адреса отправляются один раз.

### Отправка

Нажмите «Отправить». В таблице сразу появятся строки на каждый адрес. Таблица обновляется сама: «Отправка…» → «Доставлено» или «Не доставлено», затем по мере прочтения — «Прочитано». Недоступный адрес определяется за 3 секунды; подсеть /24 обрабатывается за несколько секунд.

### Таблица

| Колонка | Содержание |
|---|---|
| Отправлено | время отправки |
| Сообщение | заголовок (или начало текста) |
| IP | адрес получателя |
| Компьютер | имя компьютера (приходит от агента) |
| Пользователь | кто нажал «Прочитано» |
| Доставка | Доставлено / Не доставлено / Отправка… |
| Прочтение | Прочитано / Не прочитано / — |
| Время прочтения | когда нажата кнопка |
| Примечание | причина, если не доставлено |

Новые отправки — сверху. Внизу окна — сводка: всего, доставлено, прочитано, не доставлено. История сохраняется между запусками (последние 5000 записей) и пополняется отметками «Прочитано», даже если отправитель был закрыт и открыт заново. Кнопка «Очистить историю» удаляет все записи.

### Как повторить отправку тем, кому не доставлено

Автоматической очереди нет. Отправьте сообщение ещё раз на нужные адреса — компьютеры, уже получившие его, получат новое сообщение (с новым номером).

## 8. Мобильное приложение

Тот же движок, интерфейс для телефона: три вкладки внизу.

**Отправка** — карточки «Кому» и «Сообщение», большая кнопка «Отправить». После отправки приложение само переходит на вкладку «Статусы».

**Статусы** — вверху плитки: Всего / Доставлено / Прочитано / Ошибки. Ниже карточки по каждому адресу: IP, имя компьютера, цветные метки статуса, имя пользователя, время прочтения, причина ошибки. Цветная полоска слева: зелёная — прочитано, оранжевая — доставлено, но ещё не прочитано, красная — не доставлено, серая — идёт отправка.

**Настройки** — общий ключ (значок 👁 показывает его), состояние приёма отметок о прочтении (зелёный индикатор — порт слушается), очистка истории.

### Сборка под Android

1. Установите Android SDK, NDK и JDK, укажите их в Qt Creator: `Правка → Параметры → Устройства → Android` (кнопка «Set Up SDK»). Для Qt 6.11 подойдёт NDK и SDK, предложенные Qt Creator.
2. В `Проекты` включите комплект **Android Qt 6.11.2 arm64-v8a** (для большинства современных телефонов).
3. Включите на телефоне режим разработчика и отладку по USB, подключите кабель.
4. Выберите цель `LanMessengerMobile` и запустите (`Ctrl+R`) — приложение установится на телефон.
5. Для APK-файла: `Сборка → Build Android APK`. Для публикации потребуется подпись (`Проекты → Build Steps → Build Android APK → Sign package`).

### Условия работы

* Телефон должен быть в сети, из которой достижимы компьютеры: Wi-Fi предприятия (без «изоляции клиентов») или VPN. Через мобильный интернет без VPN адреса `192.168.*` недоступны.
* «Прочитано» приходит, пока приложение открыто. Если телефон спал или был в другой сети, агенты повторяют отправку отметки каждые 20 секунд, и статусы обновятся, как только приложение снова станет доступным по IP, с которого шла рассылка.
* Если у телефона изменился IP-адрес (переподключение к Wi-Fi), отметки по старым отправкам не дойдут — агент пытается связаться с тем IP, с которого пришло сообщение. Не меняйте сеть, пока ждёте «Прочитано», или читайте статусы с ПК-версии.

## 9. Что видит получатель

Через несколько секунд после отправки (окно проверяется каждые 3 секунды) на экране появляется окно поверх всех программ:

* заголовок и время отправки;
* текст сообщения — **только для чтения**, текст можно выделить и скопировать, изменить нельзя;
* кнопка **«Прочитано»**.

Окно нельзя закрыть крестиком, Esc или Alt+F4 — только нажатием «Прочитано» (при завершении сеанса Windows окно не мешает выходу, сообщение при этом остаётся непрочитанным и покажется при следующем входе). Если сообщений несколько — они показываются по очереди, от старых к новым. Если пользователь не вошёл в Windows — сообщение ждёт его входа.

## 10. Статусы и что они означают

| Статус | Значение |
|---|---|
| Отправка… | Соединение с компьютером устанавливается. |
| **Доставлено** | Служба агента приняла сообщение и подтвердила это подписанным ответом. |
| **Не доставлено** | Агент не ответил: см. «Примечание» (таймаут, отказ в соединении, неверный ключ). |
| — (в колонке «Прочтение») | Сообщение не доставлено — читать нечему. |
| **Не прочитано** | Доставлено, пользователь ещё не нажал «Прочитано». |
| **Прочитано** | Пользователь нажал кнопку; в таблице имя пользователя и время. |

Типичные причины «Не доставлено»:

| Примечание | Причина |
|---|---|
| Таймаут | Компьютер выключен, не в сети, адрес не существует или порт 5600 закрыт брандмауэром (пакеты отбрасываются). |
| Connection refused / отказ в соединении | Компьютер включён, но служба агента не запущена или не установлена. |
| Агент отклонил сообщение (неверный ключ?) | Ключ в отправителе не совпадает с ключом, вшитым в MSI этого компьютера. |

## 11. Общий ключ

Общий ключ — это пароль, которым подписываются сообщения и отметки о прочтении. Агент принимает только сообщения с верной подписью, а отправитель — только отметки с верной подписью.

* Ключ задаётся при сборке MSI (`-SharedKey`) и хранится на клиентах в реестре: `HKLM\SOFTWARE\LanMessenger\SharedKey`.
* В отправителе вводится вручную (ПК: поле «Ключ»; телефон: «Настройки»).
* Используйте длинный (16+ символов) случайный ключ.
* **Смена ключа:** пересоберите MSI с новым ключом и установите как обновление (раздел 13), либо задайте `SHAREDKEY=...` через MST, либо измените значение в реестре (перезапуск службы не нужен — ключ читается при каждом сообщении):
  ```powershell
  Set-ItemProperty HKLM:\SOFTWARE\LanMessenger -Name SharedKey -Value "НовыйКлюч"
  ```
* До завершения смены ключа на всех компьютерах сообщения на «непереключённые» будут отклоняться — это видно в таблице.

## 12. Сеть, порты, брандмауэр

| Куда | Порт | Направление | Назначение |
|---|---|---|---|
| Компьютеры-получатели | TCP **5600** | входящий от отправителя | доставка сообщений |
| Отправитель (ПК или телефон) | TCP **5601** | входящий от компьютеров | отметки «Прочитано» |

* На получателях правило брандмауэра создаёт MSI («LAN Messenger Agent (TCP 5600)», все профили, любой источник). Чтобы ограничить источник, измените область правила в `wf.msc` (например, только подсеть администраторов) или настройте правило отдельной GPO.
* На ПК отправителя порт 5601 разрешите при первом запуске (запрос Windows) либо вручную:
  ```powershell
  New-NetFirewallRule -DisplayName "LAN Messenger Sender" -Direction Inbound -Protocol TCP -LocalPort 5601 -Action Allow -Profile Domain,Private
  ```
* Между подсетями и VPN-сегментами маршрутизатор/межсетевой экран должны пропускать TCP 5600 туда и 5601 обратно.
* Порты фиксированы в коде (`common/protocol.h`: `kAgentPort`, `kServerPort`); изменение требует пересборки всех компонентов.

## 13. Обновление и удаление

**Обновление.** Соберите новую версию MSI (при необходимости увеличьте `Version` в `installer\Product.wxs`) и установите поверх: MSI обнаружит старую версию, остановит службу, заменит файлы и запустит службу заново. Для GPO — добавьте новый пакет с опцией «Обновить существующий пакет» или замените MSI на сетевом ресурсе и пересоздайте развёртывание.

**Удаление.**

```powershell
msiexec /x LanMessengerAgent.msi /qn
```

Служба останавливается и удаляется, файлы и правило брандмауэра удаляются, ключ и автозапуск — тоже. Папка данных `C:\ProgramData\LanMessenger` остаётся — при необходимости удалите вручную. Через GPO: в свойствах пакета → «Удаление» → «Удалить это приложение при выходе компьютера из области действия» либо удалите пакет с опцией «Немедленно удалить приложение».

## 14. Где хранятся данные

| Что | Где |
|---|---|
| Программы агента | `C:\Program Files\LAN Messenger Agent\` |
| Общий ключ (клиент) | реестр `HKLM\SOFTWARE\LanMessenger\SharedKey` |
| Автозапуск UI-хелпера | реестр `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run` → `LanMessengerUI` |
| Полученные сообщения (клиент) | `C:\ProgramData\LanMessenger\messages.json` — пользователи имеют только чтение. Прочитанные сообщения, по которым отметка доставлена отправителю, удаляются через 30 дней. |

| Настройки и история (телефон) | внутреннее хранилище приложения |

## 15. Диагностика проблем

**Всё «Не доставлено» с «Таймаут».**
1. С машины отправителя: `Test-NetConnection <IP> -Port 5600`. Если `False` — проблема в сети или брандмауэре.
2. Проверьте, что адрес принадлежит включённому компьютеру: `ping <IP>`.
3. На целевом компьютере: `Get-NetFirewallRule -DisplayName "LAN Messenger*"`.

**«Отказ в соединении».** На целевом компьютере: `Get-Service LanMessengerAgent`. Если службы нет — MSI не установился (смотрите журнал установки: `msiexec /i ... /l*v install.log`; для GPO — журнал событий «Приложение», источник MsiInstaller). Если остановлена — `Start-Service LanMessengerAgent`.

**«Агент отклонил сообщение (неверный ключ?)».** Сравните ключ в отправителе и на компьютере:
`Get-ItemProperty HKLM:\SOFTWARE\LanMessenger | Select SharedKey`. Нет пробелов в начале/конце? Совпадает регистр?

**«Доставлено», но у пользователя нет окна.**
* Пользователь вошёл в Windows уже после установки? Нужен повторный вход — или запустите `LanMessengerUI.exe` вручную.
* Проверьте, что процесс запущен в сессии пользователя: `Get-Process LanMessengerUI`.
* Проверьте автозапуск: `Get-ItemProperty HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run`.
* Лишний запуск не опасен: второй экземпляр в той же сессии сразу завершается.

**Пользователь прочитал, а статус «Не прочитано».**
1. Отправитель должен принимать подключения на порту 5601: в статусной строке не должно быть сообщения «Не удалось открыть порт 5601» (порт занят другой копией программы?).
2. Брандмауэр отправителя должен разрешать входящий 5601 (см. раздел 12).
3. С компьютера получателя: `Test-NetConnection <IP отправителя> -Port 5601`.
4. Агент повторяет отправку каждые 20 секунд — статус обновится сам, когда связь появится.
5. Не менялся ли IP отправителя после отправки (особенно у телефона)?

**Отладка вручную.** Остановите службу (`Stop-Service LanMessengerAgent`) и запустите агента в консоли: `LanMessengerAgent.exe --console` — сообщения об ошибках (занятый порт и т.п.) выводятся в окно.

## 16. Ограничения и безопасность

Честно о том, чего система не делает:

* **Шифрования нет.** Сообщения передаются по сети открытым текстом; подпись (HMAC-SHA256) защищает от подделки и подмены, но не от прослушивания. Не пересылайте пароли и конфиденциальные данные. При необходимости пропускайте трафик через VPN.
* **Ключ на клиенте читаем.** Раздел реестра HKLM доступен на чтение локальным пользователям; знающий ключ пользователь может отправить кому-либо поддельное сообщение. Ключ защищает сеть от посторонних, но не от недоверенных локальных пользователей. Ограничьте источники порта 5600 брандмауэром (раздел 12), чтобы принимать сообщения только с адресов администраторов.
* **Нет очереди у отправителя.** Выключенному компьютеру сообщение не будет доставлено позже; нужна повторная отправка.
* **Только текст.** Форматирование, вложения и ссылки не поддерживаются. Максимум 20 000 символов.
* **Несколько сессий на одном компьютере** (терминальный сервер): сообщение показывается во всех сессиях; пользователь, нажавший «Прочитано» первым, засчитывается как прочитавший.
* **Часы.** Время в таблице показывается по часам отправителя и отметка прочтения — по часам компьютера получателя; значительное расхождение времени может быть заметно.
* Пользователь с правами администратора может остановить службу или удалить программу.

## 17. Частые вопросы

**Нужно ли устанавливать что-то на отправителе?** Нет, `LanMessengerSender` — портативная папка; запускается без установки.

**Можно ли отправить одному человеку?** Да — укажите его IP одним адресом.

**Можно ли отправить по имени компьютера?** Нет, только по IP. Для компьютеров с DHCP используйте резервирование адресов.

**Что если пользователь выключил компьютер, не нажав «Прочитано»?** Сообщение хранится в `messages.json` и будет показано снова при следующем входе.

**Что если отправитель был выключен, когда пользователь нажал «Прочитано»?** Агент хранит отметку и повторяет отправку каждые 20 секунд, пока отправитель не примет её.

**Можно ли использовать несколько отправителей?** Да, с одним ключом. Каждый видит статусы только своих отправок; отметка «Прочитано» уходит тому, кто отправил сообщение.

**Работает ли на Windows 7/8?** Не проверялось; Qt 6 требует Windows 10 и новее.

**Как узнать версию?** `Get-Item "C:\Program Files\LAN Messenger Agent\LanMessengerAgent.exe" | Select VersionInfo`; в мобильном приложении — внизу вкладки «Настройки».
